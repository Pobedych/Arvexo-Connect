# Performance (Core Web Vitals) — connect.arvexo.ru

**Статус: не оценено в рамках этой сессии** (исключено из расчёта Health Score, а не оценено «по умолчанию»)

## Причина
Измерение LCP/INP/CLS требует Lighthouse/PageSpeed Insights или живой рендеринг через Chrome MCP. В этой сессии:
- Claude in Chrome был недоступен (не подключён) на протяжении всей работы.
- Модуль `playwright` не установлен в sandbox, а сеть для `pip install` отсутствует.

## Что известно из исходного кода (не заменяет измерение)
- Фронтенд собирается в режиме Next.js `output: "standalone"`.
- На сайте нет изображений (`next/image` не используется вообще) — снижает типичный риск проблем с LCP по картинкам, но не гарантирует хороший показатель.
- CSP включает `'unsafe-inline'` для `script-src`/`style-src` (необходимо для инлайн-скриптов гидратации RSC) — само по себе не влияет на CWV, но стоит держать в уме при будущей оптимизации.

## Рекомендация
Повторить аудит производительности после восстановления доступа к Chrome MCP, либо запустить `python3 scripts/pagespeed_check.py connect.arvexo.ru` (PageSpeed Insights API) в среде с доступом к сети.
