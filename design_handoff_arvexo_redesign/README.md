# Handoff: Arvexo Connect — редизайн (лендинг, вход, личный кабинет)

## Overview
Полный визуальный редизайн сервиса **Arvexo Connect** (smart VPN с маршрутизацией: зарубежный трафик через туннель, локальный — напрямую).
Старая версия — тёмная (чёрный фон, красный glow, глянцевый глобус), выглядела «дёшево» и шаблонно.
Новая версия — **светлая editorial / премиальный B2B-стиль**: тёплый cream-фон, крупная типографика, тонкие линии вместо коробок, один акцентный цвет, моноширинные технические подписи.

Пакет покрывает 3 экрана:
1. **Лендинг** (`Arvexo Connect v2.dc.html`)
2. **Вход / регистрация** (`Arvexo Login.dc.html`)
3. **Личный кабинет** (`Arvexo Dashboard.dc.html`)

## About the Design Files
Файлы в этом пакете — это **дизайн-референсы, сделанные в HTML** (прототипы, показывающие внешний вид и поведение), **а не продакшн-код для копирования один-в-один**.
Задача: **воссоздать эти макеты в существующем кодовом окружении Arvexo** (судя по сайту — Next.js / React), используя уже принятые в проекте паттерны, компоненты и библиотеки. Текущий сайт уже реализует всю логику (оплата, выдача ключей, Telegram-бот, маршрутизация) — **меняется только визуальный слой и вёрстка**, бизнес-логику и роуты не трогаем.

Это специфические DC-HTML файлы (используют рантайм `support.js` и шаблонный синтаксис `{{ }}` / `<sc-for>` / `<sc-if>`). **Не переносите этот синтаксис в продакшн** — читайте их как референс разметки/стилей и переписывайте на компоненты вашего стека. Вся разметка — на инлайновых стилях; в проде вынесите в дизайн-токены / Tailwind / CSS-модули по вашему стандарту.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и интеракции. Воссоздавать пиксель-в-пиксель средствами вашего кодбейза. Демоданные (имена, токены, отзывы, цифры статистики) — плейсхолдеры, подключите реальные данные/API.

## Interactions & Behavior
- **Marquee**: CSS `@keyframes` translateX 0→-50%, 28s linear infinite. ВАЖНО: не делать через JS rAF — должно работать чисто на CSS.
- **Reveal-анимации на скролле НЕ использовать как блокирующие** (в прототипе от них отказались: контент должен быть виден по умолчанию, без зависимости от IntersectionObserver/JS-таймеров — иначе риск пустой страницы). Если хотите entrance-motion — только необязательный CSS, не скрывающий контент.
- **FAQ-аккордеон**: одиночное раскрытие, состояние `openIndex` (по умолчанию 0). Шеврон `transform:rotate(180deg)` при открытии, transition .25s.
- **Login-табы**: состояние `tab` (`reg`/`login`/`key`) переключает заголовок, набор полей, текст кнопки и hint.
- **Dashboard — режимы**: состояние `mode`; меняет активный сегмент + описание.
- **Dashboard — подключение**: состояние `connected` (bool); меняет цвет точки, текст статуса, узел, подпись кнопки, opacity метрик.
- **Dashboard — копирование**: `navigator.clipboard.writeText(token)`, состояние `copied=token`, сброс через 1500ms, лейбл кнопки «Копировать» → «Скопировано».
- **Hover**: ссылки nav muted→ink; pill-кнопки ink→accent (или brightness 1.06 для accent-кнопок); карточки фич — лёгкая подсветка строки; outline-кнопки — усиление рамки.
- **Transitions**: 0.2–0.25s ease на трансформах/цветах. Длинных/тяжёлых анимаций нет — стиль сдержанный.
